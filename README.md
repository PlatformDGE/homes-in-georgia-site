# Homes in Georgia website

Deploys the public website to https://hge.ge. The code lives in `site/` of
[PlatformDGE/-rentintbilisi-crm](https://github.com/PlatformDGE/-rentintbilisi-crm);
edit it there, and this repository publishes changes within about 20–25 minutes.

To publish right away: Actions → Deploy hge.ge → Run workflow.
